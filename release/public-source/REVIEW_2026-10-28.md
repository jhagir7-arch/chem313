# Chem313 v2 source review — 2026-10-28

## Corrections

- Starter drawings now actually drive the calculation. Drafts are isolated by molecule, stay mounted across tabs, and Run reads a fresh editor snapshot instead of a delayed global copy. Empty/failed editor snapshots cannot run.
- The calculation report supplies canonical identity; selecting saved results shows their actual molecule. A synchronous run guard prevents duplicate dispatch from menu/keyboard events.
- Force-field coverage uses RDKit's checks on the complete hydrogenated structure, replacing an inaccurate element whitelist. UFF mercury and MMFF sodium ion are regression examples.
- Multi-record SDF input is rejected explicitly instead of silently truncating. Undefined stereochemistry must be specified; no arbitrary stereoisomer is presented as the drawn input.
- The host bounds startup, validates its loopback origin and kills/reaps failed startup children. Unsupported Stop was removed. A returning watchdog callback terminates its thread.
- The interface no longer requests a remote Google font. Version/contracts now identify this shell as 2.0.0-alpha.1 rather than reusing preview.6.
- A native-engine smoke harness verifies real water/methane/ethanol/phenol calculations, artifact hashes and independent energy reconstruction. A separate notice collector records exact dependencies and blocks incomplete binary packaging. License-looking source filenames such as copying.rs are not accepted as license texts.

## Verification record at source staging

- Earlier baseline: 296 backend tests passed.
- Changed catalog/watchdog checks: 20 passed. App unit checks: 8 passed. Rust host checks: 2 passed. Notice collector checks: 7 passed. TypeScript passed. The earlier production frontend bundle passed; the final rebuild is a separate check.
- Full backend rerun: 294 passed, 4 subprocess timeouts. A focused rerun had 7 passed and 3 timeouts. Both ran under severe machine memory pressure (approximately 49 GB swap); this is an observed confounder, not proof that the failures are harmless.
- Frozen engine starts with --help, but the required real API workflow timed out before its startup banner. Thus no successful calculation from the newly frozen binary is claimed here. A development-wrapper smoke did pass four real calculations with independent energy checks; it does not validate the frozen artifact.
- The notice inventory mapped 324 native payloads and 44 fonts, retained the PyInstaller exception, and failed on 12 objc2-family notice gaps. Mapping is not blanket legal clearance, especially for static/transformed components.

## Release boundary

This source alpha permits review and reproducible builds. Do not offer a new installer unless that platform's workflow, notice gate and practical app test have passed. Quantum engines, Qwen, add-on packs, updater and a durable long-job queue are not part of the shipped v2 workflow. Older frontend/Swift sources remain for migration and are not the current desktop target.
