# Contributing

Open an issue with a reproducible example before proposing a large change. Use synthetic or rights-cleared data and remove private paths and identifiers.

Contributions are provided under Apache-2.0. Preserve upstream copyright and license notices; identify copied or adapted material and its source. Do not contribute code or data you lack authority to submit.

Run the core benchmark, frontend tests and frontend build described in README.md. For engine changes, include the exact engine version, inputs, units, convergence criteria and validation limits. A normal process exit is not proof of scientific convergence.
